# M2 editor verification

The audited CodeMirror 5 integration is retained. All addons are local and additional commands/folding are lazy loaded. C/C++/Python syntax, bracket handling, smart indentation, comments, line commands, autocomplete identifiers/snippets, search flags, multi-selection, folding, settings, shortcuts and diagnostics use the existing editor and real runtime.

Diagnostics retain raw Clang/Python errors beside friendly explanations. Formatting is deliberately conservative: C/C++ indentation only; multiline/raw strings are preserved, Python whitespace cleanup only. It is not clang-format or Black. Column selections use Alt-drag on hardware devices; Android selection handles remain platform owned.

Five recently opened file documents retain independent undo histories. Each edit is journaled before the debounced full save; recovery validates project, file, base revision and every change. Native pause and page lifecycle events flush saves. Storage failures remain visible and never clear existing saved data.

Passed unit tests for search, formatter, diagnostics and recovery; Playwright exercises commands, search flags, real Clang compilation/diagnostics, formatting with runtime output, AA light syntax colours, composition events, per-file undo, interrupted-save recovery, Python indentation, 10,000 lines, rotation and 200% UI text. Incremental edit in 10,000 lines measured 4.00 ms on local headless Chromium (unthrottled). Existing project and upgrade UI suites pass. Synthetic composition coverage does not replace physical Android swipe-typing validation. Throttled budgets and native installation are release checks.
