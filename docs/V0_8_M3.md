# M3 Bit and effects

Bit is now a locally generated layered SVG rig with soft gradient shading, rim highlights, independently animated body, arms, eyes and pupils. `bit.play(name, {queue, duration})` supports eleven named states, bounded queues and immediate interruption. Pointer tracking updates once per animation frame, only for visible mascots. Speech bubbles accompany rewards and retries; Mascot Lab exposes every state and effect.

Confetti, XP, flame, crown and sparkle effects are bounded DOM particles using only transform/opacity; low-core or low-memory devices receive fewer particles. Hidden tabs stop effects. Reduced-motion removes animation and particles while retaining readable expressions and feedback. Store skin identifiers, ownership and ledger stay intact.

Playwright verifies every state, interruption/queue, speech, particle caps, reduced motion and the lab. The implementation is below 20 KB, well below the 1.5 MB asset budget. Physical-device frame measurements remain release checks.
