# M1 — overlay and creation foundation

One CBOverlays stack owns modal/menu/drawer/dropdown/editor-popover lifecycle, native dialog adapters, outside/Back/Esc/swipe dismissal, focus trap/restore and document scroll lock. App-level Back chains were removed. OS document/share pickers remain platform-owned. Dismissal only asks when the creation form contains unsaved changes; ordinary saved settings dismiss immediately. Existing destructive data actions retain their explicit prompts.

Project creation defaults to a unique suggested name, C++ and a Hello World template. Tap New project, then Create; customization is optional. Language/template changes update the preview. Inline validation retains the form, language runtime descriptions wrap rather than clip, fields and buttons are at least 48 CSS px, dialog height follows the visible viewport, and long labels wrap while the dialog scrolls.

Validation: 32 cases cover widths 320/360/412/768, Midnight/Paper, root UI fonts 100%/200%, normal/long pseudo-locale labels. Behavioral checks cover all dismissal routes, dirty confirmation/keep/discard, focus trap/restore, shared dropdowns, two-tap creation and keyboard viewport resizing. Original project compilation/export/reload and compact-editor/boss regressions also run. The new headless browser is a development test executable only, never an APK dependency.
